### PASO 2: Ejecutar Schema SaaS
1. En Supabase Dashboard → SQL Editor
2. Copia el contenido de `supabase-schema-saas.sql`
3. Ejecuta en Supabase

```bash

# Llena con tus credenciales de Supabase, WhatsApp y Gemini
```

### PASO 4: Probar Localmente
```bash
npm run dev
# Visita http://localhost:3000/dashboard
```
