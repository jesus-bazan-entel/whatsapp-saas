## 🔧 Próximos Pasos

### 1. Subir a GitHub
```bash
# Opción 1: Token (Recomendado)
git config --global user.name "Jesus Bazan"
git config --global user.email "jesus.bazan@gmail.com"
git push -u origin main
# Cuando pida contraseña, pega tu GitHub token

# Opción 2: SSH (Más seguro)
ssh-keygen -t ed25519 -C "jesus.bazan@gmail.com"
git remote set-url origin git@github.com:jesus-bazan-entel/whatsapp-saas.git
git push -u origin main
```

Ver: `GITHUB_PUSH_INSTRUCTIONS.md`

### 2. Configurar Supabase
1. Crear proyecto en https://supabase.com
2. Ejecutar `supabase-schema-saas.sql` en SQL Editor
3. Copiar credenciales a `.env.local`

### 3. Configurar WhatsApp Business API
1. Obtener credenciales de Meta Developers
2. Llenar variables de entorno
3. Configurar webhook en Meta Dashboard

### 4. Configurar Gemini API
1. Obtener API key de Google AI Studio
2. Llenar variable de entorno

### 5. Lanzar
```bash
npm run dev
# Visita http://localhost:3000/dashboard
```
