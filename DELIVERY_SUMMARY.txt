================================================================================
                            HOW TO GET STARTED
================================================================================

STEP 1: Read Documentation (30 minutes)
1. Open START_HERE.md
2. Follow the quick navigation
3. Read QUICK_START.md for 5-minute overview

STEP 2: Get Credentials (15 minutes)
1. Create Supabase project → Get URL, Anon Key, Service Role Key
2. Create WhatsApp Business Account → Get Phone Number ID, Access Token, Verify Token
3. Create Gemini API Key → Get API key from Google AI Studio

STEP 3: Configure Environment (5 minutes)
1. Copy .env.example to .env.local
2. Fill in all credentials from Step 2

STEP 4: Set Up Database (5 minutes)
1. Open Supabase SQL Editor
2. Copy entire content from supabase-schema.sql
3. Paste and run

STEP 5: Start Development (2 minutes)
1. Run: npm install (if not already done)
2. Run: npm run dev
3. Visit: http://localhost:3000/dashboard

STEP 6: Configure Webhook (10 minutes)
1. Run: ngrok http 3000
2. Copy ngrok URL
3. Go to Meta Dashboard → WhatsApp → Configuration
4. Set Webhook URL: https://your-ngrok-url.ngrok.io/api/whatsapp/webhook
5. Set Verify Token: Your WHATSAPP_VERIFY_TOKEN
6. Subscribe to "messages"

STEP 7: Test (5 minutes)
1. Send message to your WhatsApp Business number
2. Check dashboard at http://localhost:3000/dashboard
3. AI should respond automatically

TOTAL TIME: ~45 minutes
